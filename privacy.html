Polityka prywatności – Gmail MCP

Obowiązuje od: 23 września 2026

Czym jest aplikacja

Gmail MCP to prywatne narzędzie uruchamiane lokalnie na komputerze jego właściciela, przeznaczone wyłącznie do jego własnego użytku. Nie jest oferowane innym osobom.

Jakie dane są używane

  • Aplikacja korzysta z Gmail API z uprawnieniem tylko do odczytu (gmail.readonly).
  • Odczytuje metadane wiadomości (temat, nadawca, data, nazwy załączników) oraz treść załączników wskazanych przez użytkownika.
  • Aplikacja nie wysyła, nie usuwa i nie modyfikuje wiadomości.

Gdzie dane trafiają

  • Pobrane załączniki są zapisywane wyłącznie na lokalnym dysku użytkownika.
  • Token dostępu OAuth jest przechowywany lokalnie na komputerze użytkownika.
  • Metadane wyników wyszukiwania są przekazywane do asystenta Claude, z którego korzysta użytkownik, w ramach jego własnej sesji.
  • Dane nie są sprzedawane, udostępniane stronom trzecim ani wykorzystywane do reklam.

Usunięcie dostępu

Dostęp można w każdej chwili cofnąć na stronie myaccount.google.com/permissions oraz usuwając lokalny plik token.json.

Zgodność z zasadami Google

Wykorzystanie informacji otrzymanych z interfejsów API Google jest zgodne z Google API Services User Data Policy, w tym z wymogami Limited Use.
